Display and navigate a 2D map

A basemap provides geographic context: roads, labels, terrain and imagery. This map begins over Marburg, Germany.

What you see

The map fills the upper part of the page. Zoom and compass are at the top left, a metric scale bar at the bottom left, and a basemap toggle at the bottom right.

How it works

The <arcgis-map> element creates the map. Its basemap, center and zoom attributes configure the initial view. Child components add controls using slot positions. No JavaScript is needed to construct the map.

Try it

  1. Zoom and pan to another location, then inspect the scale bar.
  2. Switch between topographic and imagery basemaps.
  3. Open the code panel and change center, zoom or basemap. Click Run code.

What's next?

Maps can display feature layers, graphics, popups and many other web components. Basemaps provide context; operational layers carry your application data.
