Explore terrain in 3D

A 3D scene combines a basemap with elevation and a virtual camera. It is useful when height and terrain change the interpretation of a location.

What you see

A tilted view of the landscape near Marburg. Zoom, navigation mode and compass controls are in the upper-left corner.

How it works

The <arcgis-scene> element creates a 3D view. The ground attribute requests World Elevation; camera-position, camera-tilt and camera-heading define the initial viewpoint. Your API key must have access to the basemap and elevation services.

Try it

  1. Move and rotate the camera with the scene controls.
  2. Modify camera-tilt to compare a top-down view with an oblique view.
  3. Change camera-heading and click Run code.

What's next?

3D applications can display buildings, integrated meshes, point clouds and scene layers. Prefer a 2D map when elevation or perspective does not add useful information.
