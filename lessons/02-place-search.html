Find addresses and places

Geocoding converts a place name or postal address into a geographic location you can display on a map.

What you see

The top-right search field suggests matching addresses and places. Selecting a result navigates to the location and displays a marker.

How it works

The <arcgis-search> component connects its search interface to the map. It handles suggestions, geocoding and map navigation. The browser uses your API key for the ArcGIS Geocoding service; the key needs geocoding access.

Try it

  1. Search for Marburg, Germany, then try a precise street address.
  2. Search for a landmark and compare the results.
  3. Change the initial map zoom or the search placeholder in the code panel.

What's next?

Applications can filter search sources, show multiple candidates and reverse-geocode coordinates. For precise use cases, inspect the result's match quality instead of assuming that every result identifies a rooftop.
